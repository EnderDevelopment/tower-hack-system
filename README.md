# Tower Hack System

A realistic tower hacking system for FiveM servers.

## Features

- Multiple tower locations with blips
- Hacking system with success chance and rewards
- Cooldown and required item system

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start towerhacksystem` to your server.cfg
4. Run the database.sql file to create the necessary table

## Usage

Players can hack towers by approaching them and using the required item. The success chance and rewards are configurable.

## Configuration

The config.lua file contains settings for:

- Tower hack cooldown
- Reward amount
- Required item
- Success chance
- Tower locations
